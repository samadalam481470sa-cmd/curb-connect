# Existing feature registry

Permanent identifiers for behaviour that exists in the repository at commit `c91a8cc`. This file is
the answer to "does this already exist?" — check it before adding anything.

Status and verification values are defined in [README.md](README.md). `Verification: unit` means the
behaviour is covered by the executed baseline (337 unit tests, exit 0); it does not mean an HTTP,
database or browser path was exercised.
