# Field Pro Android (TWA)

Thin Trusted Web Activity wrapper around the Field Pro PWA. The full runbook — what is
already built, the owner-only Play Console steps, and how push works — lives in
`docs/android-twa.md` at the repo root.

`twa-manifest.example.json` is a Bubblewrap template. Every value in it is a
**placeholder** (host, package name, fingerprints) and must be replaced before use;
nothing in this folder is a buildable Android project yet, and nothing here claims a
Play Store listing exists.
